# Travaux de robotique

Ce depot contient les laboratoires du cours **420-1SX-SW - Robotique**.

## Projets

- `labo_01` : affichage SSD1306, mesure de distance, soleil et voiture animes.
- `labo_02` : deplacement autonome du robot, sonar, moteurs et anneau de DEL.

Chaque projet Arduino se trouve dans un dossier portant le meme nom que son fichier `.ino`.

## Environnement utilise

- Arduino IDE
- Arduino AVR Boards 1.8.6
- MakeBlock Drive Updated 3.30.0
- Adafruit GFX et Adafruit SSD1306 pour le laboratoire 01
